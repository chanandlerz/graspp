# Graspp

A personal iOS reference app for design notes, code snippets, and design fundamentals.

## Overview

Graspp is a SwiftUI-based app designed to store and organize design concepts, typography rules, spacing systems, and code references. 

## Purpose

Graspp addresses a specific learning gap: applying design fundamentals (layout, typography, spacing, contrast) in a functional iOS app. It serves as both a working reference tool and a design practice project.

## Core Features

- Four content categories: Typography, Spacing, Layout, and Design Fundamentals
- Article browsing with markdown-rendered content
- Favorites and Recently Viewed tracking via UserDefaults
- Search functionality with search history
- Tab-based navigation (My Shelf, Category, Search)

## Technical Stack

- SwiftUI for interface design
- SwiftData for data persistence
- Dynamic Type support for accessibility
- System colors for sufficient contrast

## Accessibility

Built with accessibility as a first-class requirement:

- Larger Text: Full Dynamic Type support across all size categories
- Sufficient Contrast: System colors that respond to accessibility settings
- Aligned with Apple Accessibility Nutrition Label criteria

## Design Process

From wireframe to working app. Every design decision prioritizes simplicity and clarity. Components include navigation pills, card layouts, and hierarchical text styling informed by iOS design guidelines.
